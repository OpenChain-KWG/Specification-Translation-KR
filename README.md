
# ISO/IEC 5230 한국어 번역 프로젝트

이 저장소는 [ISO/IEC 5230](https://openchainproject.org/license-compliance) (OpenChain 규격)의 한국어 번역을 위한 공간입니다.

## 공식 번역본

OpenChain 규격의 공식 번역본은 [통합 저장소](https://github.com/OpenChain-Project/License-Compliance-Specification/tree/master/2.1/ko)에서 확인할 수 있습니다.

## 저장소 구조
* [release](./release) : 번역 완료된 공식 버전
* [original](./original) : 버전별 영문 원본
* [translate](./translate) : 버전별 한국어 번역 작업 공간
* [CONTRIBUTOR.md](./CONTRIBUTORS.md) : 기여자 명단
* [glossary.txt](./glossary.txt) : 번역 단어 목록

## 기여 방법

1. [translate/2.1/](translate/2.1) 디렉토리에 있는 md 파일을 확인하세요. 각 파일은 영문 원본과 한국어 번역이 단락별로 구성되어 있습니다.
2. 한국어 번역 부분을 검토하고 개선이 필요한 경우:
   - Pull Request를 제출하거나
   - 프로젝트 관리자에게 이메일로 의견을 보내주세요.

**참고**: 2022년 3월 기준, 2.1 버전 규격의 번역이 완료되어 공식 릴리스되었습니다.

## 공식 한국어 버전 다운로드

공식 한국어 버전은 [OpenChain 프로젝트 GitHub 저장소](https://github.com/OpenChain-Project/Specification/tree/master/Official/ko/2.1)에서 다운로드할 수 있습니다.
